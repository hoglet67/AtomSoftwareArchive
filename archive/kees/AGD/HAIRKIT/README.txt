Mr Hair and the Kitty Katacombs:
--------------------------------

It's that time again when we're here to help our hero Mr Hair in this brand new Arcade Style Platformer/Puzzler.
You'll be blasting baddies and solving puzzles as you go whizzing down waterfalls and transporting into magical whirlwinds in frantic search for your beloved pussy cats in the flooded Katakombs!
Mrs Hair and the kids are  preying for everyone's safe return. 
Good Luck!

Controls

1. Keyboard  
	Q is Up
	A is down
	P is Right
	O is Left
	M is Shoot and will Activate Objects 
2. Kempston Joystick
3. Sinclair Joystick

===================================================================
System requirements:
===================================================================

- Standard Acorn Atom
- 32 KB RAM
- 8 KB video RAM (#8000-#9FFF)
- Joystick connected to keyboard matrix (Optional)
- Joystick connected to PORTB AtoMMC interface (Optional)

===================================================================
Joystick (optional JOYMMC):
===================================================================

The joystick is connected to PORTB of the AtoMMC interface with 
softwareversion 2.9. The connections are like this:

AtoMMC  Joystick
-----------------
 PB0  -  Right
 PB1  -  Left
 PB2  -  Down
 PB3  -  Up
 PB4  -  Jump
 PB5  -  nc
 PB6  -  nc
 PB7  -  nc

 GND  -  GND

If direction is active, bit = 1

===================================================================
Joystick (optional JOYKEY):
===================================================================

The joystick is connected parallel to row 1 of the keyboard matrix.

  Q   - UP
  O   - LEFT
  P   - RIGHT
SPACE - FIRE

===================================================================
Tape/Disk and AtoMMC version:
===================================================================

Tape version:

  HAIRKITTY.CSW, Tapefile for Atomulator, to start the game, type: *RUN"AGD"

Disk version:

  HAIRKITTY.DSK, Diskfile for emulators, to start the game, type *RUN"KKRUN"

AtoMMC version:

  KKRUN  = Basic introscreen
  KKSCR  = Titlescreen
  KKCODE = Gamecode

  To start the game, type: *KKRUN
