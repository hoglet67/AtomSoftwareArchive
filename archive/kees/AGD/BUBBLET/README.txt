Bubble Trouble:
---------------

Bobbly's messed up again! This time he's lost the ancient stars that provide his village with endless soap.
Help this friendly bubble recover the lost stars. You'll have to face a multitude of dangers in 26 colorful rooms.
It won't be an easy task, as our protagonist is constantly moving.
Oh, and you'll have to be quick, as you also have a limited time to complete each room.
Luckily, on your adventure you'll find aids and mechanisms that will make your mission less complicated... and extra lives hidden in some rooms!

CONTROLS

 A/D :  Move left/right
SPACE: Action
  M  : Music
  P  : Pause
  H  : Return to main menu

You can redefine the controls to your liking,
or use Kempston Joystick and Sinclair 2.

===================================================================
System requirements:
===================================================================

- Standard Acorn Atom
- 32 KB RAM
- 8 KB video RAM (#8000-#9FFF)
- Joystick connected to keyboard matrix (Optional)
- Joystick connected to PORTB AtoMMC interface (Optional)

===================================================================
Joystick (optional JOYMMC):
===================================================================

The joystick is connected to PORTB of the AtoMMC interface with 
softwareversion 2.9. The connections are like this:

AtoMMC  Joystick
-----------------
 PB0  -  Right
 PB1  -  Left
 PB2  -  Down
 PB3  -  Up
 PB4  -  Jump
 PB5  -  nc
 PB6  -  nc
 PB7  -  nc

 GND  -  GND

If direction is active, bit = 1

===================================================================
Joystick (optional JOYKEY):
===================================================================

The joystick is connected parallel to row 1 of the keyboard matrix.

 A/D :  Move left/right
SPACE: Action
  M  : Music
  P  : Pause
  H  : Return to main menu

===================================================================
Tape/Disk and AtoMMC version:
===================================================================

Tape version:

  MUSHSOUP.CSW, Tapefile for Atomulator, to start the game, type: *RUN"AGD"

Disk version:

  MUSHSOUP.DSK, Diskfile for emulators, to start the game, type *RUN"MSRUN"

AtoMMC version:

  MSRUN  = Basic introscreen
  MSSCR  = Titlescreen
  MSCODE = Gamecode

  To start the game, type: *MSRUN
