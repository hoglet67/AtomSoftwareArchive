Cocain Bear:
------------

(Load in 128k mode for ingame music)

-In this game you play a bear trapped in a strange situation.

-The bear is controlled with O,P,Q,A and SPACE if keyboard is chosen in the menu or with joystick both Kempston and
Sinclair.

-When you pick up a POWER pack (they are white) the POWER counter will fill up (5 units) and
300 points will be achieved. At the start of the game and after losing a life you will have 5 units
of POWER as an advantage.

-Pressing the space key or the joystick button will cause the bear to enter FURY mode for a few short
instants (as long as POWER units are available). While in FURY mode the bear will destroy
whoever gets within reach, spending a POWER unit and getting 100 points per victim. if the bear
collides with an enemy while not in FURY mode, he will lose one of his initial three lives, as well as if he falls
to the water or collides with a cactus, obviously.

-Some enemies are car-driving and some are shooting up, FURY mode can save us but we can not destroy that enemies.

-The objective of the game is to get the maximum score, so you will have to go around the whole map in search of
POWER packs to be able to finish with the maximum number of enemies before losing the 3 lives you have.
There is always a POWER pack on one of the 15 full map screens.

-The marker at the top of the screen tells you at all times the number of lives remaining, the
available POWER units, the points record and the current score.

-This game is free and non-profit.

-This game is intended exclusively for adults.

===================================================================
System requirements:
===================================================================

- Standard Acorn Atom
- 32 KB RAM
- 8 KB video RAM (#8000-#9FFF)
- Joystick connected to keyboard matrix (Optional)
- Joystick connected to PORTB AtoMMC interface (Optional)

===================================================================
Joystick (optional JOYMMC):
===================================================================

The joystick is connected to PORTB of the AtoMMC interface with 
softwareversion 2.9. The connections are like this:

AtoMMC  Joystick
-----------------
 PB0  -  Right
 PB1  -  Left
 PB2  -  Down
 PB3  -  Up
 PB4  -  Jump
 PB5  -  nc
 PB6  -  nc
 PB7  -  nc

 GND  -  GND

If direction is active, bit = 1

===================================================================
Joystick (optional JOYKEY):
===================================================================

The joystick is connected parallel to row 1 of the keyboard matrix.

  Q   - UP
  O   - LEFT
  P   - RIGHT
SPACE - FIRE

===================================================================
Tape/Disk and AtoMMC version:
===================================================================

Tape version:

  COCAINE.CSW, Tapefile for Atomulator, to start the game, type: *RUN"AGD"

Disk version:

  COCAINE.DSK, Diskfile for emulators, to start the game, type *RUN"CBRUN"

AtoMMC version:

  CBRUN  = Basic introscreen
  CBCODE = Gamecode

  To start the game, type: *CBRUN
