Blocktor Woot:
--------------

Blocktor Woot in the Sloanyverse of Madness
Sloanysoft is proud to present a minigame that combines our love of Doctor Who, Lego and self referential generic platformers.  

The Game can be downloaded here: https://spectrumcomputing.co.uk/entry/42649/ZX-Spectrum/Blocktor_Woot

Blocktor Woot in the Sloanyverse of Madness is part of the excellent Woot 2023 package of fun ZX Spectrum games and tech demos.

These are all available to download for free here:  https://spectrumcomputing.co.uk/forums/viewtopic.php?t=10714

Keys:

  Q   - UP
  O   - LEFT
  P   - RIGHT
 SPC  - Fire 

Atom version done by Kees van Oss.

===================================================================
System requirements:
===================================================================

- Standard Acorn Atom
- 32 KB RAM
- 8 KB video RAM (#8000-#9FFF)
- Joystick connected to keyboard matrix (Optional)
- Joystick connected to PORTB AtoMMC interface (Optional)

===================================================================
Joystick (optional JOYMMC):
===================================================================

The joystick is connected to PORTB of the AtoMMC interface with 
softwareversion 2.9. The connections are like this:

AtoMMC  Joystick
-----------------
 PB0  -  Right
 PB1  -  Left
 PB2  -  Down
 PB3  -  Up
 PB4  -  Jump
 PB5  -  nc
 PB6  -  nc
 PB7  -  nc

 GND  -  GND

If direction is active, bit = 1

===================================================================
Joystick (optional JOYKEY):
===================================================================

The joystick is connected parallel to row 1 of the keyboard matrix.

  Q   - UP
  O   - LEFT
  P   - RIGHT
 SPC  - Fire 

===================================================================
Tape/Disk and AtoMMC version:
===================================================================

Tape version:

  BLOCKTOR.CSW, Tapefile for Atomulator, to start the game, type: *RUN"AGD"

Disk version:

  BLOCKTOR.DSK, Diskfile for emulators, to start the game, type *RUN"BWRUN"

AtoMMC version:

  BWRUN  = Basic introscreen
  BWSCR  = Titlescreen
  BWCODE = Gamecode

  To start the game, type: *BWRUN
