Driar:
------

Help Driar collect all the stars in each of the 30 levels that make up the game.
Keep in mind that you can exit through the edges of the screen and appear on the opposite side, so take advantage of this, as it will be vitally important.
Driar is the conversion for ZX Spectrum (128 Kb.) of the game created for NES in 2012 by Stefan Adolfsson & David Eriksson.
You also have a "Remastered" and expanded version for computer:   Driar Revival

CONTROLS

 A/D :  Walk left/right
  W  : Jump
SPACE: Run
  M  : Turn music on/off
  P  : Pause
  H  : Return to main menu

You can redefine the controls to your liking,
or use Kempston Joystick and Sinclair 2.

IMPORTANT: If you are using the Kempston Joystick,
press the '2' key to pause the game.

===================================================================
System requirements:
===================================================================

- Standard Acorn Atom
- 32 KB RAM
- 8 KB video RAM (#8000-#9FFF)
- Joystick connected to keyboard matrix (Optional)
- Joystick connected to PORTB AtoMMC interface (Optional)

===================================================================
Joystick (optional JOYMMC):
===================================================================

The joystick is connected to PORTB of the AtoMMC interface with 
softwareversion 2.9. The connections are like this:

AtoMMC  Joystick
-----------------
 PB0  -  Right
 PB1  -  Left
 PB2  -  Down
 PB3  -  Up
 PB4  -  Jump
 PB5  -  nc
 PB6  -  nc
 PB7  -  nc

 GND  -  GND

If direction is active, bit = 1

===================================================================
Joystick (optional JOYKEY):
===================================================================

The joystick is connected parallel to row 1 of the keyboard matrix.

 A/D :  Walk left/right
  W  : Jump
SPACE: Run
  M  : Turn music on/off
  P  : Pause
  H  : Return to main menu

===================================================================
Tape/Disk and AtoMMC version:
===================================================================

Tape version:

  DRIAR.CSW, Tapefile for Atomulator, to start the game, type: *RUN"AGD"

Disk version:

  DRIAR.DSK, Diskfile for emulators, to start the game, type *RUN"DRRUN"

AtoMMC version:

  DRRUN  = Basic introscreen
  DRSCR  = Titlescreen
  DRCODE = Gamecode

  To start the game, type: *DRRUN
