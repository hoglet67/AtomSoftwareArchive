Jet Set Steamboat Willie:
-------------------------

Sometime ago we featured a game called Manic Jet Set Willy, a Manic Miner / Jet Set Willy mash up for the ZX Spectrum by Norman Sword. Well fast forward to today and yet another Jet Set Willy mash up has been announced, as thanks to Saberman giving us the heads up, we've been told that Sloanysoft has released a highly enjoyable game of Jet Set Steamboat Willie. A mash up of Mickey Mouse in a Jet Set Willy world!

Here's the latest from the itch io page."2024 sees Steamboat Willie entering the Public Domain and the 40th anniversary of Jet Set Willy. To celebrate this milestone, Sloanysoft is proud to present a wee tribute to these classics for you to enjoy on your ZX Spectrum. Featuring music from Lee Bee and made with Multi-Platform Arcade Game Designer by Jonathan Cauldwell, this is a game not to be missed"

KEYS:

 Q  - Up
 A  - Down
 O  - Left
 P  - Right
SPC - Jump
 B  - Toggle pause

Written by Davey Sloan, Sloanysoft.

Atom version done by Kees van Oss.

===================================================================
System requirements:
===================================================================

- Standard Acorn Atom
- 32 KB RAM
- 8 KB video RAM (#8000-#9FFF)
- Joystick connected to keyboard matrix (Optional)
- Joystick connected to PORTB AtoMMC interface (Optional)

===================================================================
Joystick (optional JOYMMC):
===================================================================

The joystick is connected to PORTB of the AtoMMC interface with 
softwareversion 2.9. The connections are like this:

AtoMMC  Joystick
-----------------
 PB0  -  Right
 PB1  -  Left
 PB2  -  Down
 PB3  -  Up
 PB4  -  Jump
 PB5  -  nc
 PB6  -  nc
 PB7  -  nc

 GND  -  GND

If direction is active, bit = 1

===================================================================
Joystick (optional JOYKEY):
===================================================================

The joystick is connected parallel to row 1 of the keyboard matrix.

  Q   - UP
  O   - LEFT
  P   - RIGHT
SPACE - FIRE

===================================================================
Tape/Disk and AtoMMC version:
===================================================================

Tape version:

  WILLIE.CSW, Tapefile for Atomulator, to start the game, type: *RUN"AGD"

Disk version:

  WILLIE.DSK, Diskfile for emulators, to start the game, type *RUN"SWRUN"

AtoMMC version:

  SWRUN  = Basic introscreen
  SWSCR  = Titlescreen
  SWCODE = Gamecode

  To start the game, type: *SWRUN
